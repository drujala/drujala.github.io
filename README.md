# For Ujala, With Love — static birthday landing page

## Files
- `index.html` — page structure
- `style.css` — responsive lily-themed visual design and CSS 3D-style cake
- `script.js` — candle interaction, password gate, and destination link

## Before publishing
1. Open `script.js`.
2. Replace `https://YOUR-DYNAMIC-BIRTHDAY-SITE-URL-HERE` with the full URL of your existing dynamic birthday website.
3. The password is currently `US1216`.
4. Push the three site files to a GitHub repository and enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → / (root)**.

## Important password note
Because this is a static GitHub Pages site, the password is a playful front-end gate, not real security. Anyone determined can inspect the source and discover the password or destination URL. Do not use it to protect sensitive/private information.
